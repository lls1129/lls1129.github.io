\subsection{Conclusion}
We have shown that the min-hash sketch preserves differential privacy of its inputs in several different deployment scenarios.  In the private hash setting or when inputs have individual high-entropy, Theorems~\ref{thm:PrivH} and~\ref{thm:CDDP} give practical parameter ranges for which privacy can be achieved as shown in Section~\ref{sec:eval}.  Moreover, we precisely describe the required properties on the input data necessary for privacy.  While in a setting where we can only guarantee high-entropy of the entire input set, Theorem~\ref{thm:CDDP2} gives an asymptotic privacy guarantee.  We leave it to future work to identify concrete parameters and applications where this can be practically instantiated.  We believe that these results can serve as a foundation for privacy-preserving applications of the Jaccard index.
